# Product decisions
Last verified: 2026-10-31

Decisions the user made. Don't undo or re-propose without asking. Newest first.

- **2026-10-31 — KB upkeep by reminder, not auto-writes.** A Stop hook (scripts/kb-reminder.mjs) only prints a reminder when code changed but `docs/kb/` didn't; agents still send kb-keeper a record-mode summary. Why: keeps the 2026-10-14 "one project memory, no auto Stop-hook memory" decision. Also added `pnpm kb:lint` and the [project.md](project.md) card.
- **2026-10-31 — Playwright smoke tests on the static export.** E2E runs against a static build in the dev workspace (`e2e/static-server.mjs`), not `next dev`. Why: `next dev` was too flaky under Playwright. See [testing.md](testing.md).
- **2026-10-31 — Security is a separate, later pass.** Planned: `pnpm dev` → test DB by default, a hook blocking prod commands, dev auto-login creds review. Not mixed into the CI/KB work.

- **2026-10-30 — Navigation + single home, "Combine both" (built on `dev`; not yet in a desktop release).** Two lines of nav work landed the same day (Daily Planner folded into Today, below; and a design-review nav with Today as home + a "3 pills + Plan menu" layout). The user chose **"Combine both"**, which **supersedes the "3 pills + Plan menu" plan** (no Plan menu — only one planner page is left). Why: a design review (`.design/research/repo.md`) found three overlapping "today" screens (`/today`, the `/todos` sidebar "Today", Planner "Now"), a flat 6-pill nav mixing page kinds, the Planner named three ways, and Standup highlighting Today with no sub-nav. Final:
  1. **Today (`/today`) is the single home.** The Todos daily pages (`/todos`, carryover + journal) become **"Journal"**, a tab inside Today. Today tabs = Now · Journal · Standup (weekdays only) · History. The two task lists (external-brain `tasks` vs daily-page todos) should **merge over time** — a separate, larger job, not planned yet.
  2. **Top nav = 4 pills: Today · Notes · Memory · Content Planner.** The Notes pill is back. Today stays lit on Today tabs and on `/planner`, since the Daily Planner lives inside Today.
  3. **Phone (below 768px): bottom tab bar** with the same 4 items; replaces the sideways-scrolling pill row that hid on scroll (answers the M3 pill-overflow question).
  Build choices: "Journal" is a label only (`ViewMode` stays `"todos"`, see [ui-design.md](ui-design.md) → "Nav"). Did **not** bring back New/Duplicate plan — multi-presets stay removed (Oct 2026 decision below). Open, needs the user: Today tab row left-aligned vs centred page column; "Now" tab vs "Today" page title naming; phone Journal is cramped (top bar + tabs + stacked sidebar + bottom bar). QA: `.design/qa/2026-10-30-app-navigation.md`.
- **2026-10-30 — Daily Planner folded into Today.** The Daily Planner pill is gone. The day plan is edited from Today via an "Edit day plan" dialog; `/planner` redirects to `/today?editPlan=1`. The NowView/radial clock and planner tour have no route now. (Earlier the same day, PR #27, the Todos and Notes pills were hidden; Notes came back in the combined nav above, Todos is now Journal inside Today.) See [daily-planner.md](daily-planner.md).
- **2026-10-30 — "App notes" renamed "Change requests".** UI, code and MCP tools renamed (`*_change_request`; old `*_app_note` tools removed). Stored names (`app_notes` collection, `app_note` sync kind, `app-note-` ids) kept so there's no prod migration and older desktop builds keep syncing. See [change-requests.md](change-requests.md).
- **2026-10-30 — Work on `dev`.** Always work and commit on `dev`. Don't create worktrees without asking; use a separate branch only when `dev` is busy or for an isolated test feature. (Also in `CLAUDE.md`.)

- **2026-10-27 — Memory / Project / Standup + pings (M3) build choices.** Built with the plan defaults (`docs/plans/2026-10-27-external-brain-m3.md`): a **Memory** nav pill right after Today (Todos, Notes, Daily Planner, Content Planner stay); desktop pings as proposed (weekdays 08:00–18:00, block-with-task start + standup heads-up, on/off bell). Ship web **and** desktop for a 2–3 day production trial, then collect feedback. Keep the M2 phone layout and History as they are: **declined** Shelf-first on phones and an "Only AI changes" filter (closes the M2 open questions). The 375px nav overflow question was answered on 2026-10-30 (bottom tab bar, above).
- **2026-10-27 — Today + History (M2) build choices.** Data path: the 6 memory kinds are per-record outbox sync kinds (upsert only, never deleted because a device lacks them); `change_log` syncs create-only — keeps server-first safety. History shows **all** changes (app and AI), labelled You / Claude / ChatGPT / An AI chat. Nav: a **Today** pill first and `/` redirects to `/today`; Todos, Notes, Daily Planner, Content Planner stay as they are **until a migration of old daily-page todos is decided**. History has no pill — opened from Today ("See all changes", footer link).
- **2026-10-27 — "Chat captures, the app shows" redesign (mockups only, not built).** AI chat saves tasks/decisions/ideas/routines/meeting summaries via MCP; the app shows where you are. Chose: nav = **Today · Memory · Content**; Todos + Daily Planner merge into Today; projects are cards at the top of Memory (no Projects tab); life areas (job / content / personal) shown as neutral word + icon chips, **not** priority colors; undo of an AI change = soft delete with "Bring back", plus a History page listing every AI change (trust); gentle desktop pings: yes; tasks become their own records and **workspaces are dropped**; the Decisions log comes later. Office Companion folder folds into DailyTodo. Details, plan and privacy caution: [user-needs.md](user-needs.md).

- **2026-10-26 — App notes (now "Change requests").** User wanted a quick way to jot ideas/improvements/bugs about the app itself. Chose: text + type (Idea / Improvement / Bug); entry point is a top-bar icon (the sidebar isn't on every screen) + ⌘⇧I; scope = capture + simple list + MCP tools; **delete is always soft**. User explicitly OK'd a soft-delete MCP tool (then `delete_app_note`, now `delete_change_request`) — this narrows the earlier "no delete tools" rule to "no hard deletes anywhere". See [change-requests.md](change-requests.md).
- **2026-10-26 — Content Planner MCP server.** User wanted to edit the Content Planner from ChatGPT/Claude chat. Chose: hosted online (ChatGPT needs a public URL), on the same VPS as PocketBase (Coolify, `mcp.ahayder.me`), auth by secret URL path instead of OAuth (simple, single user), powers = read/add/edit only — **no hard-delete tools** (safety; soft delete of app notes allowed since the App notes decision above). Server logs in with a 365-day impersonation token rather than a stored password (user prefers not storing the password; password login also kept failing). See [mcp-server.md](mcp-server.md).

- **2026-10-14 — Todos/Planner interview (no decision yet).** User wants a "Now + timeline" view on sit-down, welcomes gentle desktop pings, wants the Daily Planner as a guideline (not a strict schedule), and has no preference on leftovers. The "Today" merge was later agreed on 2026-10-27 (above). Details: [user-needs.md](user-needs.md).
- **2026-10-14 — One project memory.** kb-keeper + `docs/kb/` stay the only project memory. When upgrading the UI brain to v2, the user chose not to install ui-brain's `.brain/`, `brain` agent and Stop hook (avoids two competing memories).

- **2026-10-11 — Content Planner series.** User wanted to group videos into series, note the series idea, and see published counts per series. Chose: open-ended (no target episode count), no episode order, a card in at most one series, counts also on the main page. Series stay quiet — they don't change Next up, the ship meter or stages. Relaxes the "no tags" narrowness only for series.
- **2026-10-08 — Content Planner Editing stage + publish info.** User asked for Editing after Shoot next ("Start editing") and optional per-platform links + transcript on Published — "nothing mandatory". They praised Focus + Shelf as natural and intuitive: keep its feel.
- **2026-10-07 — Server-first sync.** After the data loss the user chose "server is the truth; devices only send their own changes", as bulletproof as possible. See [sync-persistence.md](sync-persistence.md).
- **Oct 2026 — Content Planner redesign to Focus + Shelf.** The user has ADHD, shiny-object syndrome and analysis paralysis; Kanban and Gallery truncated cards. Goal: publish 4–5 pieces a week; uses phone and desktop equally. **Declined:** auto-picked Now card with swap / "pick for me", hiding Ideas as a "parked" count, hard Shoot-next cap of 3 (stays soft 5). Chose only the weekly ship tracker. Legacy columns folded into Inbox at the user's request. Before adding helpers, ask what the next pain point is.
- **Oct 2026 — Daily Planner NOW + Set up.** Radial editor, budgets, roles, multi-presets and tour removed from the UI (data kept).
